# SunShift India — React Dashboard

A premium dark dashboard for SunShift India, rebuilt with **React + TypeScript + Tailwind CSS + Recharts + Lucide**. It recreates the reference dashboard design (near-black `#191919` canvas, charcoal `#242424` cards, electric blue `#4169F5` and solar orange `#FF944D` accents) with all 13 SunShift views.

## Run it

```bash
cd dashboard
npm install
npm run dev      # http://localhost:5174
npm run build    # production bundle in dist/
```

## Pages (13)

| Route | Page |
| --- | --- |
| `/` | Overview — Solar Panel Monitoring, Monthly Generation, Energy Production chart, Solar System Status |
| `/live-energy-flow` | Live Energy Flow — animated solar / home / battery / grid diagram with time scrubber |
| `/forecast` | Solar Forecast — 7-day cards, hourly curve, week trend |
| `/battery` | Battery Management — state-of-charge gauge, dispatch controls, charge/discharge profile |
| `/appliances` | Appliance Scheduler — searchable picker, best solar windows, today's plan |
| `/scenarios` | What-if Scenarios — sky, demand, grid outage; save to run history |
| `/day-ahead-plan` | Day-ahead Energy Plan — hourly balance, dispatch table, CSV export |
| `/savings` | Savings & Environmental Impact — savings trend, tariff control, CO₂ impact |
| `/run-history` | Run History — searchable/filterable table of saved runs |
| `/reports` | Reports — CSV exports with previews |
| `/settings` | Settings — home profile, array, battery, tariff, data integration notes |
| `/rooftop-estimator` | Rooftop Estimator — capacity, yield, cost, subsidy, payback |
| `/solar-calculator` | Solar Savings Calculator — sizing from bill, 25-year projection |

## Architecture

```
src/
  lib/            ← data layer (swap this for the real backend)
    engine.ts     ← simulation engine, ported from the SunShift Node engine (src/sim.js)
    mockData.ts   ← sample appliances, schedule, run history (labelled as sample in the UI)
    store.tsx     ← React context store, localStorage persistence
    types.ts      ← shared types
    format.ts     ₹ / kWh / date formatters, CSV download helper
  components/
    ui.tsx        ← Card, Button, Select, Slider, Toggle, Modal, Badge, StatTile, Toast…
    charts.tsx    ← Recharts wrappers (production chart, line series, tooltip theme)
    Sidebar.tsx / Topbar.tsx / DashboardLayout.tsx
    SolarPanelArt.tsx ← SVG solar panel illustration
  pages/          ← one file per view
```

**All figures are modelled estimates** generated by the built-in planning engine — no backend endpoints are called, and the UI labels data as sample/modelled throughout. To connect the real SunShift energy engine and Supabase, replace the load/persist functions in `src/lib/store.tsx` (and `mockData.ts`); UI components stay unchanged.

State persists to `localStorage` (`sunshift-dashboard-state-v1`) so the demo works standalone across reloads.
